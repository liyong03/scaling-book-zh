# 如何扩展你的模型（How To Scale Your Model）— 简体中文译本

这是 [How To Scale Your Model](https://jax-ml.github.io/scaling-book/)（Jacob Austin 等，Google DeepMind，2025）的**非官方**简体中文译本。

- 中文版在线阅读：https://liyong03.github.io/scaling-book-zh/
- 英文原著：https://jax-ml.github.io/scaling-book/ ，源码：https://github.com/jax-ml/scaling-book
- 原项目以 MIT 许可证发布（见 [LICENSE](LICENSE)），本译本沿用同一许可证并保留原版权声明。
- 译文如有出入，请以英文原文为准。

本仓库基于原仓库提交 `3ae1dee` 翻译。构建方式与原项目相同（Ruby + Jekyll）：

```
bundle install
bundle exec jekyll serve
```
