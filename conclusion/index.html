延伸阅读

有很多相关的文章，包括以下这些：

  • TPU Deep Dive：一篇很棒的深入剖析 TPU 架构的文章，风格与本书一脉相承。
  • Domain specific architectures for AI inference：一篇对硬件和模型的深入探讨，风格与本书一脉相承。
  • A Domain-Specific Supercomputer for Training Deep Neural Networks：最早的 TPU 论文之一，包含许多关于 Google TPU 项目的精彩细节，这些内容本书没有涉及。
  • Making Deep Learning Go Brrrr From First Principles：一篇更侧重 GPU 和 PyTorch 的教程，讲解 LLM 的 Roofline 分析与性能工程。
  • Writing TPU Kernels with Pallas：TPU 编程越来越多地涉及用 Pallas 编写自定义 kernel。这一系列文档讨论了如何编写 kernel，以及许多本书未提及的更底层的 TPU 细节。
  • How to Optimize a CUDA Matmul Kernel for cuBLAS-like Performance: a Worklog：虽然专门针对 GPU 和 CUDA，但这是一篇出色的博客文章，展示了如何在 CUDA 中优化矩阵乘法（matmul）kernel。它或许能帮你深入理解 TPU 与 GPU 的区别。
  • Distributed arrays and automatic parallelization：这是一份非常好的 JAX 并行 API 指南，也是学习如何实际实现我们在这里讨论的一些思想的好途径。
  • Rafi Witten’s High Performance LLMs 2024 Class：我们的前同事 Rafi 开过一门很棒的 TPU 性能工程课程，所有幻灯片都放在 GitHub 上。其中很多内容比本书讲得更深入。
  • [2211.05102] Efficiently Scaling Transformer Inference：一篇详细讨论 Transformer 推理数学的论文，本文档的许多内容都受其启发。
  • Huggingface Ultra-Scale Playbook：可以算是本书的 GPU 版对应读物，它更深入地讨论了 PyTorch 在训练中如何实现各种并行技术和节省内存的技术。
  • Transformer Inference Arithmetic：一篇博客，包含许多与本书相同的思想，还有一些出色的插图。
  • Stanford CS336 Slides and Videos：一门非常棒的 Stanford 课程，涵盖了 LLM 训练和部署的许多细节，并配有一些有用的练习。其中作业 1 和作业 2 尤其相关。
  • Stas Bekman’s ML Engineering Handbook：一份非常实用的 ML 基础设施指南，涵盖了本书没有涉及的主题，比如如何与云服务商谈判、集群管理，以及 GPU 吞吐量的实测数据。
  • ezyang’s blog：一位 PyTorch 负责人的博客，内容涵盖分片与 PyTorch 的方方面面，包括一篇 PyTorch 内部机制指南和一篇关于分片矩阵乘法的文章。这里还有很多其他好内容。
  • The Anatomy of Collective Communication：一篇不错的 GPU 和 TPU 集合通信详解，风格与本书一脉相承。它对 N 维集合通信和 GPU 集合通信的讲解比本书更好。

这一领域仍有大量空间留给全面系统的写作，我们希望本书能激励更多这样的作品！我们也相信这是一个值得学习和研究的、大有可为的领域。在很多情况下，即使手头没有很多硬件加速器，也可以开展这方面的研究。
